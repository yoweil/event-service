# Сервис событий

Сервис хранит события по скважинам, позволяет пользователям настраивать типы и поля,
прикреплять файлы и обмениваться данными с внешними программами.

Текущий этап - проектирование архитектуры и модели данных. Код приложения пока
не создан; язык, фреймворки и инфраструктура нужно будет выбрать.

## Документы

- [Черновик модели данных](docs/data-model.md): варианты хранения, сущности,
  версии типов и примеры событий.
- [Детальная схема таблиц](docs/database-schema.md): колонки, ключи, ограничения,
  индексы и правила записи данных.
