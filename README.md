# Сервис событий

Сервис хранит события по скважинам, позволяет пользователям настраивать типы и поля,
прикреплять файлы и обмениваться данными с внешними программами.

Сервер на Go позволяет через HTTP создавать типы событий, читать каталог и настройки
полей для формы, сохранять карточки в PostgreSQL и искать события по скважине, периоду и значениям полей

## Документы

- [Черновик модели данных](docs/data-model.md): типы событий, дополнительные поля,
  примеры карточек и поиска.
- [Детальная схема таблиц](docs/database-schema.md): колонки, ключи, ограничения,

- [HTTP API](docs/http-api.md) с примерами создания типа, записи и чтения карточки.
